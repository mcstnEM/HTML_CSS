# Partiel HTML-CSS

## Partie A : QCM

### 1. Quel est le but de l'élément `<head>` dans un document HTML ?
A. Contenir le contenu principal du document  
B. Définir la structure et la mise en page du document  
C. Contenir des méta-informations sur le document  
D. Afficher des images

### 2. Quelle balise HTML est utilisée pour créer un lien hypertexte ?
A. `<link>`  
B. `<a>`  
C. `<href>`  
D. `<img>`

### 3. Que signifie CSS ?
A. Feuilles de Style en Cascade  
B. Feuilles de Style Informatique  
C. Feuilles de Style Créatives  
D. Feuilles de Style Colorées

### 4. Comment inclure un fichier CSS externe dans un document HTML ?
A. En utilisant la balise `<style>`  
B. En utilisant la balise `<css>`  
C. En utilisant la balise `<link>`  
D. En utilisant la balise `<script>`

### 5. Laquelle des propriétés CSS suivantes est utilisée pour changer la couleur de fond d'un élément ?
A. `color`  
B. `font-color`  
C. `background-color`  
D. `bgcolor`

### 6. Quelle est la balise HTML correcte pour insérer un saut de ligne ?
A. `<break>`  
B. `<lb>`  
C. `<br>`  
D. `<newline>`

### 7. Comment créer une liste ordonnée en HTML ?
A. `<ul>`  
B. `<ol>`  
C. `<li>`  
D. `<list>`

### 8. Quelle propriété CSS contrôle la taille du texte ?
A. `font-style`  
B. `text-size`  
C. `font-size`  
D. `text-style`

### 9. Comment ajouter un commentaire en CSS ?
A. `// Ceci est un commentaire`  
B. `<!-- Ceci est un commentaire -->`  
C. `/* Ceci est un commentaire */`  
D. `# Ceci est un commentaire`

### 10. Quelle est la propriété d'affichage par défaut de l'élément `<div>` ?
A. `inline`  
B. `block`  
C. `inline-block`  
D. `none`

### Réponses :
1. C. Contenir des méta-informations sur le document
2. B. `<a>`
3. A. Feuilles de Style en Cascade
4. C. En utilisant la balise `<link>`
5. C. `background-color`
6. C. `<br>`
7. B. `<ol>`
8. C. `font-size`
9. C. `/* Ceci est un commentaire */`
10. B. `block`
